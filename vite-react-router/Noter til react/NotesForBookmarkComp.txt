## BookmarkButton Component - Notes

### What We Created:
- Generic BookmarkButton component (src/components/BookmarkButton.jsx)
- Handles bookmark toggle logic ONLY (no styling)
- Parent page controls all appearance and content
- Works everywhere: cards, lists, overlays, etc.

### Component Props:
- itemId: Unique ID of item to bookmark
- isBookmarked: true/false current state
- onToggle: Callback function (itemId, shouldBookmark) => {}
- className: CSS classes for styling
- style: Inline styles
- children: Content to display (parent decides based on isBookmarked)

### Key Features:
- Pure logic component (no built-in styling)
- Stops event bubbling (won't trigger parent clicks)
- Parent decides what to display (icon, text, emoji, etc.)
- Same component for add AND remove
- Works in any layout (vertical cards, horizontal cards, buttons, etc.)

### How It Works:
1. Parent tracks bookmarked items in state (array of IDs)
2. Parent provides toggle handler (adds or removes from array)
3. Parent passes current bookmark state to button
4. Button handles click and calls onToggle with new state
5. Parent decides what content to show based on isBookmarked

### Parent Component Pattern:
```jsx
// 1. Track bookmarked items
const [bookmarkedIds, setBookmarkedIds] = useState([]);

// 2. Toggle handler
const handleToggle = (itemId, shouldBookmark) => {
    if (shouldBookmark) {
        setBookmarkedIds([...bookmarkedIds, itemId]);
    } else {
        setBookmarkedIds(bookmarkedIds.filter(id => id !== itemId));
    }
};

// 3. Check if bookmarked
const isBookmarked = (itemId) => bookmarkedIds.includes(itemId);
```

### Usage Examples:
```jsx
// Simple icon button
<BookmarkButton
    itemId={item.id}
    isBookmarked={isBookmarked(item.id)}
    onToggle={handleToggle}
    style={{ fontSize: '2rem', background: 'none', border: 'none' }}
>
    {isBookmarked(item.id) ? '★' : '☆'}
</BookmarkButton>

// Bootstrap button
<BookmarkButton
    itemId={item.id}
    isBookmarked={isBookmarked(item.id)}
    onToggle={handleToggle}
    className="btn btn-primary"
>
    {isBookmarked(item.id) ? 'Saved' : 'Save'}
</BookmarkButton>

// Overlay on image (IMDB style)
<BookmarkButton
    itemId={item.id}
    isBookmarked={isBookmarked(item.id)}
    onToggle={handleToggle}
    style={{
        position: 'absolute',
        top: '8px',
        left: '8px',
        width: '36px',
        height: '36px',
        backgroundColor: isBookmarked(item.id) ? '#1f90f3' : 'rgba(0,0,0,0.6)'
    }}
>
    {isBookmarked(item.id) ? '✓' : '+'}
</BookmarkButton>
```
