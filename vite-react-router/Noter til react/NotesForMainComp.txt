## MainDisplay Component - Notes

### What We Created:
- Reusable MainDisplay component (src/components/MainDisplay.jsx)
- Displays comprehensive info for titles (movies/shows) OR actors
- Follows existing code patterns (like RandPic.jsx)
- Uses existing ContainerCstyle class and #1f90f3 accent color

### Component Props:
- type: 'title' or 'actor'
- data: object with all display information

### Title Display Includes:
- Header (title + year)
- Banner image
- Rating (stars + number)
- Plot description
- Genre badges (styled with app colors)
- Cast list
- Directors

### Actor Display Includes:
- Header (name + birth year)
- Portrait/poster image
- Biography
- Known for list

### Key Features:
- Default values prevent crashes if data missing
- Conditional rendering (only shows data that exists)
- Inline styles match existing design
- Fully documented with comments

### Usage Example:
```jsx
<MainDisplay 
    type="title" 
    data={{
        title: 'Movie Name',
        banner: 'url',
        plot: 'description',
        rating: 9.3,
        year: 1994,
        genres: ['Drama'],
        actors: [...],
        directors: [...]
    }} 
/>
```
