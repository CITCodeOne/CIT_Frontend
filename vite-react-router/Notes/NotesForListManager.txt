# 📋 ListManager Component - Reusable List Management

## Overview

Component File: src/components/ListManager.jsxCreated a dedicated, reusable `ListManager` component that handles all list management functionality. This component can be used across different pages (Individual, Title, etc.) to provide a consistent user experience.

---

## Benefits of the Component Approach



The ListManager is a Bootstrap modal component that provides a unified interface### 1. **Reusability**

for adding titles, individuals, or other items to user-created lists. It supports- Use the same component for adding actors, movies, directors, etc. to lists

both adding to existing lists and creating new lists on-the-fly.- Consistent UI/UX across the entire application

- No code duplication

### 2. **Maintainability**
- All list logic in one place
- Easy to update and fix bugs
- Centralized API integration point

### 3. **Flexibility**
- Supports different item types (individual, title, etc.)
- Customizable callbacks for success/error handling
- onHide (function)- Easy to extend with new features 
- Callback when modal should close
- Called on Cancel button, close button, or backdrop click### 4. 

**Clean Code**
- Pages stay focused on their main purpose
- Separation of concerns
- Better testing capabilities

## Component API

### Props

```jsx
<ListManager
  show={boolean}              // Controls modal visibility
  onHide={function}           // Called when modal should close
  itemName={string}           // Display name of the item (e.g., "Tom Cruise")
  itemId={string}             // ID of the item to add
  itemType={string}           // Type: 'individual' or 'title'
  userId={string}             // ID of the logged-in user
  onSuccess={function}        // Called when item added successfully
  onError={function}          // Called when an error occurs
/>
```

### Callbacks

**onSuccess** receives:
```javascript
{
  action: 'created' | 'added',  // Whether list was created or item added to existing
  listName: string,              // Name of the list
  itemName: string               // Name of the item that was added
}
```

**onError** receives:
```javascript
Error object
```

## Usage Examples

### Example 1: Individual Page (Current Implementation)

```jsx
import ListManager from '../components/ListManager';

function Individual() {
  const [showListModal, setShowListModal] = useState(false);
  
  const handleListSuccess = (result) => {
    if (result.action === 'created') {
      alert(`Created list "${result.listName}" and added ${result.itemName}!`);
    } else {
      alert(`Added ${result.itemName} to "${result.listName}"!`);
    }
  };

  return (
    <>
      <MainDisplay
        customAction={{
          label: 'Add to List',
          variant: 'primary',
          icon: '📋',
          onClick: () => setShowListModal(true)
        }}
      >
        {/* page content */}
      </MainDisplay>

      <ListManager
        show={showListModal}
        onHide={() => setShowListModal(false)}
        itemName={individual?.name}
        itemId={individualId}
        itemType="individual"
        userId={userId}
        onSuccess={handleListSuccess}
        onError={(err) => console.error('Error:', err)}
      />
    </>
  );
}
```

## Features

### Current Features

1. **List Selection Dropdown**
   - Shows all user's existing lists
   - Displays item count for each list
   - "Create New List" option

2. **Create New List**
   - Input field appears when "Create New List" selected
   - 50 character limit with validation
   - Smart placeholder text based on item type

3. **Loading States**
   - Loading spinner while fetching lists
   - Disabled controls during operations
   - Loading button state during submission

4. **Error Handling**
   - Error alerts with dismiss option
   - Callback for parent component to handle errors
   - Clear error messages

5. **Validation**
   - Empty list name prevention
   - No selection prevention
   - Form validity checking

6. **User Feedback**
   - Confirmation of which list item will be added to
   - Success/error callbacks
   - Loading indicators

## Component Structure

```
ListManager.jsx
├── State Management
│   ├── selectedList (which list to add to)
│   ├── newListName (name for new list)
│   ├── userLists (fetched from API)
│   ├── loading (submission state)
│   ├── loadingLists (fetch state)
│   └── error (error messages)
│
├── Effects
│   └── fetchUserLists (when modal opens)
│
├── Functions
│   ├── fetchUserLists() - Get user's lists from API
│   ├── handleAddToList() - Add item to list
│   ├── handleClose() - Reset and close modal
│   └── isFormValid() - Check form validity
│
└── UI Components
    ├── Modal Header (title)
    ├── Modal Body
    │   ├── Error Alert (if error)
    │   ├── List Selection Dropdown
    │   └── New List Name Input (conditional)
    └── Modal Footer
        ├── Cancel Button
        └── Add to List Button (with loading state)
```

## Migration Guide for Other Pages

To add list functionality to any page:

1. **Import the component:**
   ```jsx
   import ListManager from '../components/ListManager';
   ```

2. **Add state for modal:**
   ```jsx
   const [showListModal, setShowListModal] = useState(false);
   ```

3. **Add button/action:**
   ```jsx
   <Button onClick={() => setShowListModal(true)}>
     Add to List
   </Button>
   ```

4. **Add the component:**
   ```jsx
   <ListManager
     show={showListModal}
     onHide={() => setShowListModal(false)}
     itemName={item.name}
     itemId={item.id}
     itemType="title"  // or "individual"
     userId={userId}
     onSuccess={(result) => alert('Success!')}
   />
   ```
