## TMDB Integration - Temporary Implementation Notes

### Date: December 15, 2025
### Status: TEMPORARY - Pending Backend API Updates

---

## Overview
The Movie Database (TMDB) API is being used as a **temporary fallback** for missing backend endpoints. Once the backend provides these endpoints with proper data, TMDB integration can be removed or kept as fallback only.

---

## What TMDB Provides (Currently Used)

### Individual Page (src/pages/Individual.jsx)
1. **Profile Pictures** - `tmdb.getPersonPhoto(individual.name)`
   - Fetches high-quality profile pictures for actors/directors/producers
   - Used when backend doesn't provide `image` field
   - Fallback: DefaultProfilePicture.jpg

2. **Photo Gallery** - `tmdb.getPersonPhotos(individual.name, 12)`
   - Fetches multiple photos for carousel display
   - Returns array of image URLs
   - Grouped into slides of 3 for Bootstrap carousel

### Title Page (src/pages/Title.jsx)
1. **Movie/Show Posters** - `tmdb.getTitlePoster(title.name, title.mediaType, title.startYear)`
   - Fetches high-quality posters for movies/TV shows
   - Used when backend doesn't provide poster field
   - Fallback: Image-not-found.png

2. **Cast Photos** - `tmdb.getMultiplePersonPhotos(actorNames)`
   - Fetches profile pictures for all cast members in parallel
   - Returns object keyed by actor name: `{ "Tom Hanks": "url...", ... }`
   - Used for both "Top Cast" and full "Cast" sections

3. **Similar Titles** - `tmdb.getSimilarTitles(title.name, title.mediaType, title.startYear, 20)`
   - Fetches recommended similar movies/shows
   - Backend API tried first, TMDB used as fallback if backend returns empty
   - Returns array with: id, name, poster, startYear, mediaType

4. **Similar Title Posters** - `tmdb.getTitlePoster()` for each similar title
   - Fetches posters for similar titles returned by backend
   - Only called if similar title doesn't already have poster URL
   - Ensures all carousel items have images

## TMDB Integration Files

### Core Integration Module
**src/business-logic-layer/TmdbIntegration.jsx**
- `getPersonPhoto(name)` - Single person profile picture
- `getPersonPhotos(name, limit)` - Multiple photos for gallery
- `getMultiplePersonPhotos(names)` - Batch fetch for cast photos
- `getTitlePoster(name, mediaType, year)` - Movie/show poster
- `getSimilarTitles(name, mediaType, year, limit)` - Similar recommendations

### API Configuration
**tmdbApiConfig.json** (root directory)
- Contains TMDB API key and base URLs
- Not tracked in git for security
- Example structure:
```json
{
  "apiKey": "your_tmdb_api_key_here",
  "baseUrl": "https://api.themoviedb.org/3",
  "imageBaseUrl": "https://image.tmdb.org/t/p/w500"
}
```

## Data Flow Examples

### Individual Page - Profile Picture
```
1. Backend: GET /v2/individuals/{id}
   Returns: { id, name, birthYear, deathYear } (NO IMAGE)
   
2. Frontend: Checks if individual.image exists
   → If NO → Call tmdb.getPersonPhoto(individual.name)
   
3. TMDB: Search person by name → Get first result → Return profile_path
   
4. Display: Show TMDB photo OR fallback to DefaultProfilePicture.jpg
```

### Title Page - Cast Photos
```
1. Backend: GET /v2/titles/{id}/individuals
   Returns: [{ id, name, character }] (NO IMAGES)
   
2. Frontend: Extracts actor names into array
   → Call tmdb.getMultiplePersonPhotos(actorNames)
   
3. TMDB: Parallel fetch for all actors → Return { "Name": "photoUrl", ... }
   
4. Display: Use castPhotos[actor.name] for each cast member
```

### Title Page - Similar Titles
```
1. Backend: GET /v2/titles/{id}/similar
   → Try backend first
   
2. If backend returns data:
   → Use backend similar titles
   → Fetch TMDB posters for each title (if missing)
   
3. If backend returns empty or errors:
   → Fallback to tmdb.getSimilarTitles()
   → TMDB provides complete data (name, poster, year)
   
4. Display: Show carousel with posters and bookmark buttons
```

## Performance Considerations

### Parallel Fetching
- Cast photos fetched in parallel using `Promise.all()`
- Similar title posters fetched in parallel
- Reduces total wait time significantly

### Caching
- Currently: No caching implemented
- Future: Could cache TMDB results in localStorage or memory
- Would reduce API calls for frequently viewed pages

### Rate Limiting
- TMDB free tier: 40 requests per 10 seconds
- Current usage: Well within limits
- Multiple requests batched using Promise.all()
