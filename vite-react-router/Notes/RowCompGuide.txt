# RowComp Component Documentation

## Overview

`RowComp` is a unified, flexible component that replaces `ListComp` and `GridListComp` with a single variant-based approach. Built with React Bootstrap, it supports three layout modes: **grid**, **list**, and **carousel**.

---

## Why RowComp?

### Problems Solved:
- ✅ Eliminates confusion between `ListComp` and `GridListComp`
- ✅ Fixes broken import in `Individual.jsx` (`List` component doesn't exist)
- ✅ Provides consistent React Bootstrap Row/Col usage
- ✅ Single component with multiple layout variants
- ✅ Proper responsive behavior out of the box

### Before (Multiple Components):
```jsx
// GridListComp - for grids
<GridListComp items={cast} renderItem={(actor) => <MediaCard {...actor} />} />

// SimpleList - for lists (wraps in divs)
<SimpleList items={reviews} renderItem={(review) => <ReviewCard {...review} />} />

// List - DOESN'T EXIST (broken import in Individual.jsx)
<List items={titles} renderItem={(title) => <MediaCard {...title} />} />
```

### After (One Component):
```jsx
// Grid variant
<RowComp items={cast} renderItem={(actor) => <MediaCard {...actor} />} variant="grid" />

// List variant
<RowComp items={reviews} renderItem={(review) => <ReviewCard {...review} />} variant="list" />

// Carousel variant
<RowComp items={titles} renderItem={(title) => <MediaCard {...title} />} variant="carousel" />
```

---

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | Array | `[]` | Array of items to render |
| `renderItem` | Function | **required** | Function that renders each item `(item, index) => JSX` |
| `variant` | String | `'grid'` | Layout variant: `'grid'`, `'list'`, or `'carousel'` |
| `className` | String | `''` | Additional CSS classes for the Row |
| `colProps` | Object | `{xs: 12, sm: 6, md: 4, lg: 3}` | Bootstrap Col props (grid variant only) |
| `emptyMessage` | String | `'No items to display'` | Message when items array is empty |
| `wrap` | Boolean | `true` | Whether items should wrap to next line |

## Variants

### 1. Grid Layout (Default)

Responsive grid with Bootstrap columns. Best for: **media cards, user profiles, thumbnails**.

```jsx
<RowComp
  items={actors}
  renderItem={(actor) => (
    <MediaCard
      id={actor.id}
      type="person"
      image={actor.profilePath}
      title={actor.name}
      subtitle={actor.character}
    />
  )}
  variant="grid"
  colProps={{ xs: 12, sm: 6, md: 4, lg: 3 }}
/>
```

**Column Props Examples:**
```jsx
// 4 columns on large screens
colProps={{ xs: 12, sm: 6, md: 4, lg: 3 }}

// 3 columns on large screens
colProps={{ xs: 12, sm: 6, md: 4 }}

// 2 columns always
colProps={{ xs: 6 }}
```

---

### 2. List Layout

Full-width stacked items with separators. Best for: **reviews, comments, detailed items**.

```jsx
<RowComp
  items={reviews}
  renderItem={(review) => (
    <Card>
      <Card.Body>
        <h5>{review.author}</h5>
        <p>{review.content}</p>
        <Rating value={review.rating} />
      </Card.Body>
    </Card>
  )}
  variant="list"
/>
```

---

### 3. Carousel Layout

Horizontal scrolling row (no wrap). Best for: **"known for" titles, related items, photo galleries**.

```jsx
<RowComp
  items={knownForTitles}
  renderItem={(title) => (
    <MediaCard
      id={title.id}
      type="title"
      image={title.poster}
      title={title.name}
      size="medium"
    />
  )}
  variant="carousel"
/>
```

## Best Practices

1. **Always provide a key** - Even though RowComp uses `item.id` or `index`, provide keys in your renderItem:
   ```jsx
   renderItem={(item) => <MediaCard key={item.id} {...item} />}
   ```

2. **Use appropriate variants**:
   - Grid: Cards, thumbnails, profiles
   - List: Reviews, comments, full-width items
   - Carousel: Related items, galleries

3. **Responsive column props**:
   ```jsx
   // Good: Responsive
   colProps={{ xs: 12, sm: 6, md: 4, lg: 3 }}
   
   // Bad: Fixed width on all screens
   colProps={{ xs: 3 }}
   ```

4. **Loading states** - Handle loading outside RowComp:
   ```jsx
   {loading ? (
     <Spinner />
   ) : (
     <RowComp items={data} renderItem={...} />
   )}
   ```

## Questions?

- **Q: Should I delete GridListComp and ListComp?**  
  A: Not immediately. Migrate pages first, then deprecate old components.

- **Q: Can I nest RowComps?**  
  A: Yes, but avoid nesting same variants (e.g., grid in grid).

- **Q: What about MediaCard size prop?**  
  A: Use `size="large"` for grid, `size="medium"` for carousel.
