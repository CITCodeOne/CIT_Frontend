## 📝 Notes

### Design Decisions:

1. **Why keep old components temporarily?**
   - Allows gradual migration
   - Reduces risk of breaking changes
   - Gives time to find all usages

2. **Why three variants instead of separate components?**
   - Single source of truth
   - Consistent API
   - Easier to maintain
   - React Bootstrap best practices

3. **Column props default:**
   - `{ xs: 12, sm: 6, md: 4, lg: 3 }` = 4 columns on large screens
   - Mobile-first approach (full width on mobile)

### Common Issues:

- **Issue:** "Items not wrapping"
  - **Fix:** Check `wrap={true}` prop (default)

- **Issue:** "Carousel not scrolling"
  - **Fix:** Ensure parent has width constraint

- **Issue:** "Grid items different heights"
  - **Fix:** CSS stretches items by default, check MediaCard CSS
