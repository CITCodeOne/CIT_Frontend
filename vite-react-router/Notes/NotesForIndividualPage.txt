## Individual Page - Implementation Notes
### Last Updated: December 15, 2025

### Overview:
- Created Individual page (src/pages/Individual.jsx) for displaying actor/person details
- Uses custom hook architecture with useIndividualData hook
- Reuses MainDisplay component for consistent layout with Title page
- **TMDB Integration**: Uses TMDB API for profile pictures and photo galleries
- Route: /individual/:individualId
- Backend: https://localhost:5001 | Frontend: http://localhost:5173

### Page Sections:
1. **Header** (MainDisplay): Profile picture (TMDB) + name, job badges, lifespan (born-died), biography
2. **Photo Gallery**: TMDB carousel with 12 photos (grouped into slides of 3)
3. **Known For**: Grid with poster cards showing titles (with bookmark buttons)
4. **Filmography**: Simple list matching Title cast design (clickable rows with thumbnails)

### Key Features:
- **TMDB Profile Pictures**: Fetches high-quality profile photos when backend doesn't provide
- **TMDB Photo Gallery**: 12 photos in carousel format from TMDB
- **Bookmark Functionality**: Can bookmark titles in Known For section (uses ToggleButton)
- **Filmography List**: Simple clickable rows with thumbnails (matches Title page cast design)
- **Birth/Death Years**: Shows "1956 - Present" for living people, "1956 - 2023" for deceased
- **No Bookmark for Individuals**: Only titles can be bookmarked
- **Profession Badges**: Shows "Actor" badge by default (awaiting profession data from API)

### API Integration (src/business-logic-layer/ApiClient/ApiClient.jsx):

**Working Endpoints:**
- mdb.apiv2.individuals.getById(id) - Main individual data (name, birth/death year, rating)
- mdb.apiv2.individuals.getTitles(id) - Titles person is known for (filmography)
- mdb.apiv2.user.getBookmark(userId, titleId) - Check if title is bookmarked
- mdb.apiv2.user.addBookmark(userId, titleId) - Add title bookmark
- mdb.apiv2.user.removeBookmark(userId, titleId) - Remove title bookmark

**TMDB Integration (src/business-logic-layer/TmdbIntegration.jsx):**
- tmdb.getPersonPhoto(name) - Single profile picture for header
- tmdb.getPersonPhotos(name, 12) - Multiple photos for gallery carousel

### Architecture:

**Individual.jsx Structure:**
- Uses useIndividualData hook (returns individual, loading, error, knownForTitles, loadingKnownFor)
- Local state for TMDB photos, bookmark status, and filmography
- useEffect hooks for TMDB profile picture, photo gallery, and bookmark checks
- Conditional rendering: loading → error → no individual → success
- Prepares badges and sections arrays before rendering
- MainDisplay with biography section
- Three Container sections (Photo Gallery, Known For, Filmography)
- No ListManager needed (removed in favor of simpler design)

**useIndividualData Hook:**
- State: individual, loading, error, knownForTitles, loadingKnownFor
- 2 useEffect hooks (individual basic data, known for titles/filmography)
- All backend data fetching centralized in hook
- Returns all state to Individual component
- Note: No bookmark for individuals (only titles can be bookmarked)

**TMDB Integration in Individual.jsx:**
1. **Profile Picture** (useEffect):
   - Runs when individual data loads
   - Calls tmdb.getPersonPhoto(individual.name)
   - Sets tmdbProfilePicture state
   - Fallback to DefaultProfilePicture.jpg if TMDB fails

2. **Photo Gallery** (useEffect):
   - Runs when individual data loads
   - Calls tmdb.getPersonPhotos(individual.name, 12)
   - Groups photos into slides of 3 for carousel
   - Shows placeholder if no photos available

3. **Title Bookmarks** (useEffect):
   - Checks bookmark status for all Known For titles
   - Parallel fetch using Promise.all()
   - Stores results in titleBookmarks state object

**Bookmark Functionality:**
- Uses ToggleButton component for each Known For title
- handleTitleBookmark() function toggles bookmark state
- Calls mdb.apiv2.user.addBookmark() or removeBookmark()
- Updates titleBookmarks state immediately for responsive UI
