Quick guide: add/adjust JSON -> object mapping
=============================================

Key files
---------
- Aliases + normalize helper: src/business-logic-layer/KeyAliases.js
- Mappers (titles/individuals): src/business-logic-layer/ItemMapper.jsx
- User/bookmark/rating mapping: src/business-logic-layer/ApiClient/ApiClient.jsx
- Domain classes: src/business-logic-layer/DataClasses.jsx

How it works
------------
- Incoming keys are lowercased, punctuation stripped, then matched via alias maps to class properties.
- Objects are sealed, so only properties that exist on the class are set.

Steps to map a new field
------------------------
1) Add the property to the class in DataClasses.jsx (e.g., add `popularity: "n/a"`).
2) Add an alias in KeyAliases.js:
   - TITLE_KEY_ALIASES for titles, INDIVIDUAL_KEY_ALIASES for people,
     USER_KEY_ALIASES / RATING_KEY_ALIASES / BOOKMARK_KEY_ALIASES for user-related responses.
   - Use lowercase, no underscores/dashes for the key; value is the class property name.
   - Example: `popularityscore: "popularity"`.
3) If the value shape needs tweaking (dates, arrays), adjust the mapper (e.g., normalizeGenres or releaseDate trim).
4) Test with src/Tests/TestApiClient.jsx to see the mapped output.

Gotchas
-------
- If the class lacks the property, nothing gets assigned—add it first.
- Dates: releaseDate is trimmed to YYYY-MM-DD; years < 1920 are skipped.
- Genres: object arrays map to name/Name; strings pass through.

Need more?
----------
Search for the alias maps in KeyAliases.jsx and mirror the pattern.
